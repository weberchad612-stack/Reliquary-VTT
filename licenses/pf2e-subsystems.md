# PF2e Subsystems (acknowledgement)

The subsystem data shape in `engine/events/subsystem.js` and `rulesets/pf2e/subsystems.js` (tracks with
thresholds, parts such as obstacles, NPCs and library sections with their checks, and what is hidden from players)
follows the ideas of the **PF2e Subsystems** module for Foundry VTT by WBHarry
(https://github.com/WBHarry/pf2e-subsystems), released under the MIT License. No code from the module is copied
into this project; this note credits the design it follows.
