# examples

Open-licensed sample content only. Do not add publisher content (books, adventures, maps, art) here.

- `sample-pack/maps/sample-crypt/`: a 12 x 10 cell map drawn for this project, with one of every wall type: solid walls, a door, a locked door, a secret door, a portcullis (grate), a window, an arrow slit, an ethereal barrier, a terrain curtain and a one-way illusory wall.
- `sample-pack/maps/sample-stairwell/`: a 4 x 4 room linked to the crypt, for testing map links.
- `sample-save/maps/sample-crypt.json`: map state for the crypt: an open door, a found secret door, a known locked door, explored areas and two tokens.

The map images are generated from the wall data with `python3 tools/wall_overlay.py <map-dir> --blank`.

- `sample-pack/maps/sample-village/`: an area map (a small town): a picture with places, no grid (generated by `tools/samples/sample_village.py`). Every battle map in the pack has a starting area (`start`).
- `campaigns/keep-test/`, `campaigns/crypt-test/`: test campaigns for the board (`campaign.json` and per-map state with tokens and notes) over the sample pack. Tokens have generated ids and are named by the rules: creatures by adjective and type (the Wet-Nosed, Ragged-Eared and Scabby-Tailed Rat), and one named NPC with an alias (Varsha Kell, whom players see as the Hooded Cultist) for testing what each view shows. Each campaign has its creatures' game data (`actors/`, original builds for Kerra, Pip and Lyra, and stat-block references for the creatures) and some live state (`actorstate/`).
- `sample-pack/content/`: original stat blocks for the test creatures (not official ones) and standard items from the open rules, in the content format (`rulesets/pf2e/schemas/content.schema.json`). `pack.json` also lists the open PF2E equipment (`content/pf2e/equipment`), so Party loot can add any open item (`tools/loot.mjs find`, `add`); the pack's own items are found first. Copy one to the PC's `saves/` to load it (see `docs/best-practices/board.md`).
- `demo/`: an interactive page that runs the engine on the sample crypt (see its README).

Check them with `node tools/validate.mjs examples/sample-pack --save examples/sample-save`.
